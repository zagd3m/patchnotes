All %ED is additive in one bucket (str, skill, synergies, gear, auras). +30% from a skill level sounds big, but once your bucket is ~700–900%, it's only a few % real damage.

Formula & assumptions

Implemented model (from Bubbles' PD2 calculator, forum-verified):
baseMin = floor(dex/4 + bootMin + kickFlat×2 + dmgPlus + flatMin)
baseMax = floor(dex/3 + bootMax + kickFlat×2 + dmgPlus + flatMax)
ED% = str×1.0 + talonED + synergyED + gearED + auraED
kickDmg = floor(base × (1 + ED%/100)) + elemental
  • Single bucket: the dex "feet" term sits inside the same %ED multiplier as everything else — the vanilla two-term split does not exist in PD2.
  • Strength: each point = +1% ED (×1.0). The "80%" patch-note wording is inaccurate to the implementation.
  • +Kick Damage counts double: +30 adds 60 to min and max base before %ED.
  • Elemental flat damage: added after %ED, not scaled, and not doubled by crits.
  • Skill ED: S13 → 30 + 30×slvl (+25%/lvl per synergy); S10–12 → 25 + 25×slvl (+22%/lvl per synergy).
  • Crits: CS ×2.0 and DS ×1.5, each 75%-capped, CS checked first. Expected value = physAvg × (1 + cs + (1−cs)×ds×0.5).
  • Not modeled: crushing blow, open wounds, splash to secondary targets (same damage), target resistances/PDR.
  • Weapon damage and weapon %ED do not apply to kicks in PD2.
